# P0 Props and Environment Implementation Plan

**Goal:** Original reproducible generators and exported P0 assets on `feat/props-env`.

**Approved design:** Standalone deterministic generators; pure geometry in core,
unit tests first, thin Blender export adapters, separate asset libraries. Follow
docs/04 and ASSET_LIST variants and tighter row budgets. Use palette UVs, base
pivots, applied transforms, tree LOD/sway data, colliders and specified sockets.
Preserve imported PR_RockLarge; export original alternatives with variant names.
No external source assets, scene integration, graphics settings or protected code.

**Tech stack:** Python unittest, ruff, Blender/UPBGE background authoring (not MCP).

## Execution
- [ ] Props: tests then pure geometry and generator for Coin, GoldenFish, Buoy,
  Log, RockSmall/Med/Large, CheckpointArch, FinishGate, Signpost; include all
  inventory variants, banner rig and confetti sockets.
- [ ] Environment: tests then geometry/generator for PineTree (3 + LOD1), Bush
  (3), BankTile (4), RiverStrip and standalone SkyDay shader library.
- [ ] Run each generator with fail-closed per-row budgets. Lock every new blend
  before exporting. Never overwrite existing files without a lock.
- [ ] Add eight-column provenance for every new deliverable, with generator
  path, CC0 own-work declaration, generation notes and explicit VERIFY items.
- [ ] Run `python tools/validate_assets.py assets`, `ruff check .`, and
  `python -m unittest discover -s tests` before each logical commit.
- [ ] Review changes independently; fix scoped findings. Record exact measured
  counts and manual preview/runtime/Tier B checks rather than claiming them.
- [ ] Push only `feat/props-env` fast-forward; compare local SHA with
  `git ls-remote origin refs/heads/feat/props-env`.

## Acceptance and manual checks
Generator completion is not runtime approval. Human P2/P3 must inspect silhouettes,
palette shading, banner deformation, coin bob hookup, tree sway/LOD selection,
bank seams/foam anchors, river UV flow, collisions and sky appearance in UPBGE;
measure Tier B performance without altering any preset. Preview renders remain
VERIFY unless produced without changing graphics settings.

## Assumptions
User confirmed starting from the current baseline (no previous Batch 2 work).
Own-made rock variants coexist with, but do not resolve or reuse, the imported
rock's open QAL/CC0 question. Standalone shader assets do not assign a world or
change graphics settings in any game scene.
